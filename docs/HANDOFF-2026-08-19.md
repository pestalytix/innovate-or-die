## Phases — hard stop at the end of each; report and wait

**Phase A — Adopt core (no generation yet).**
Verify `core/` matches this layout (9 files); report missing/divergent files instead of creating them. Inventory workspace drift per above. Move the current `skills/innovate-or-die/` content to `docs/archive/v1/` (git mv, preserve history); place a copy of the retired `innovation-mode` skill in `docs/archive/innovation-mode/` when provided. Do not generate adapters, do not modify `core/`, do not commit. List working-tree changes and stop. *Gate A: Ken approves `core/` wording and drift disposition.*

**Phase B — Build script + generation.**
Write `build/assemble.py` (stdlib-only if possible): reads `core/` + `skill-meta.yaml`, emits every generated tree. SKILL.md = frontmatter from skill-meta + workflow.md body with role/reference files carried alongside; flattened web variants = single file in fixed order (principles → workflow → roles → experiment spec) with a per-target character budget and a fidelity preamble ("separated passes, no context isolation"); `.agent.md` profiles = one per role file plus an orchestrator whose instructions explicitly direct the fresh-chat-per-role handoff.
Patch hygiene applies: idempotent, dry-run flag, and a `--check` mode that regenerates to temp and diffs against committed trees (this becomes the CI drift guard). **Verify formats against current docs at build time — do not trust manifest schemas from memory:** agentskills.io spec; code.claude.com plugin/marketplace schema (`claude plugin validate` must pass); Codex `.codex-plugin` expectations; VS/VS Code `.agent.md` frontmatter; Agent Builder instruction char limit. Record each verified fact + date in `docs/COMPATIBILITY.md`. *Gate B: `--check` clean, `claude plugin validate` passes, Ken spot-reads one generated artifact per family.*

**Phase C — Attribution + repo hygiene.**
Author fields in all manifests → Ken + kenpendergast.com. README rewrite: what it does, install matrix (one row per surface incl. "M365 Copilot: paste `adapters/web/m365-copilot.md` into Agent Builder"), the three-rung fidelity ladder (agentic hosts → Copilot agent profiles → flattened web), limitations, license. LICENSE copyright line → verify current holder, set to Ken if not already. CHANGELOG.md seeded with 2.0.0 + ADR link. *Gate C: Ken reviews README.*

**Phase D — Evals.**
5 fixed problems (mixed domains; at least one where the correct finding is "conventional is near-optimal" — tests intellectual_independence against novelty-forcing). `rubric.md` = evaluator dimensions applied by a judge model. Baseline run across all three; commit. *Gate D: baseline committed; Ken reads results before any protocol tuning in response to them (tuning = new ADR + version bump).*

**Phase E — Publish + retire.**
